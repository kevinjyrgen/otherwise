# Team OtherWise – Wise Hackathon 2026

Vite + React + Tailwind CSS.

## How to run

```bash
npm install
npm run dev -- --host
```

Open the `Local` URL on your laptop. Teammates on the same Wi-Fi can open the `Network` URL on their phones.

## Team rules

- One person per file.
- Commit before larger AI changes.
- Pull before you start.
